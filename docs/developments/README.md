# Developments (moved)

The numbered development records now live in [docs/decisions/](../decisions/README.md) as
architecture decision records with frontmatter (status, date, supersession). Numbers
were kept: `developments/NNN-<slug>.md` is `decisions/0NNN-<slug>.md`. The full mapping,
with old and new statuses, is in [docs/decisions/MIGRATION.md](../decisions/MIGRATION.md).
New decisions go in docs/decisions/; planned work goes in [docs/features/](../features/README.md).
